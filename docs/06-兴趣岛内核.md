## 三、链接清单格式

一行一条，三种写法：

```
课名 | https://…/index.m3u8          ← 竖线
课名<TAB>https://…/index.m3u8        ← 从 Excel 复制
https://…/index.m3u8                ← 只有链接：用文件名当标题
```

- `#` / `//` 开头是注释；`- ` `* ` `1. ` `1、` 前缀会被剥掉
- 行尾可写时长：`[48:12]`、`(1:02:03)`、`时长=2892`（秒）→ 用于成品校验
- JSON：
  - 数组 `[{"title":"…","url":"…","camp":"…","duration":2892}]`
  - 映射 `{"课名":"https://…"}` 或 `{"<fileId>":{"url":"…","camp":"…"}}`
  - 上游的 `links.json`（只有 url）+ `names.json`（只有 name）按 **fileId 合并**成完整条目；
    只有名字没有链接的条目不会进队列
- 重复判定：优先 `fileId`，其次 URL，最后标题

## 四、下载链路与判据（实测结论，别改）

1. **先拉清单**：正文不是 `#EXTM3U` → 当直链媒体；含 `EXT-X-STREAM-INF` → 多码率；
   含 `EXT-X-KEY` → 加密清单。
2. **多码率按短边 `min(w,h)` 选流**：这批课多为竖屏（480x852 / 720x1280），
   按高度排序会误选最差一路。`max` 取短边最大；`1080/720/480` 取 ≥ 目标的最小一路。
3. **加密清单找同目录明文孪生** `v.f<编号>.m3u8`：
   - 编号来自 URL 的 `video_<num>_` 或 `v.f<num>.m3u8`
   - 请求孪生**必须去掉 `encdomain=cmv1`**，否则 403
   - `sign` 只绑目录和 `t`，不绑文件名 ⇒ 同目录别的文件复用同一个 query
   - **必须做时长校验**（容差 `max(1s, 0.5%)`）：同目录可能存在别的长视频，不校验会下错内容
4. **总字节用 12 片等距抽样外推**（`step=(n-1)/11`，片数 ≤12 全取）。
   取前 3 片实测高估 37%（直播课开头码率高）；抽样片写进缓存目录复用。
5. **分片本地名 `%05d_<basename>`**：前缀保证字典序 == 播放序（否则 `seg_10` 排在 `seg_2` 前）；
   basename 跨会话稳定（只有 `?sign=` 会变）⇒ 靠文件名就能续传。
6. **必须先字节拼接成 `all.ts` 再喂 ffmpeg**，不能用 concat demuxer（会重置时间戳，成品短 6 秒）。
   临时输出必须以 `.mp4` 结尾，否则 ffmpeg 报 "Error initializing the muxer"。
7. **进度按内容时长占比**（每片 EXTINF 精确），不是字节占比；直链音频才用字节。
8. **清理口径**：失败/中止**保留分片**；成功才清（`KeepParts` 时也留）。写反就毁掉续传本钱。

## 五、存储与状态

```
%USERPROFILE%\.hgv_tool\xqd\
├── jobs.json              链接清单 + 状态（进度不落盘）
└── parts\<md5(成品路径)[:16]>\   分片缓存
```

- 重启时**非终态一律回到「待下载」**（否则会永远显示「下载中」）
- 状态词与红果侧共用一套：待下载 / 排队中 / 解析中 / 下载中 / 封装中 / 校验中 / 已完成 / 已存在 / 已暂停 / 失败
- 「已存在」= 成品文件存在且 ≥ 10KB；点「重新扫描」按磁盘重判
- 「重新下载（清缓存）」会先删掉该成品的分片目录

## 六、界面语义

- 切到兴趣岛页时隐藏「重新授权 / 授权状态」（这一侧不需要授权）
- **双击某行 = 只下这一节**；「下载」按钮 = 有勾选只下勾选的，没勾选下所有待下载/失败的
- 「暂停」冻结分片下载（保留缓存）；「停止」中止并把状态退回待下载
- 画质下拉：最高画质（自动）/ 1080P / 720P / 480P（按短边）
- 右键：下载这一节 / 重新下载（清缓存）/ 复制链接 / 复制课名 / 打开文件夹 / 移出清单

## 七、怎么验证

离线回归已经覆盖解析/命名/队列（`Hgvd.Tests` 的 `[兴趣岛]` 组，40 项）。
真链路用 `--xqdtest`（**真下**，产物落系统临时目录）：

```bash
# 1) 造一段本地 HLS（3 个 4 秒分片）
ffmpeg -y -f lavfi -i "testsrc=size=640x360:rate=25:duration=12" \
       -f lavfi -i "sine=frequency=440:duration=12" \
       -c:v libx264 -preset veryfast -pix_fmt yuv420p -c:a aac -shortest \
       -f hls -hls_time 4 -hls_list_size 0 -hls_segment_filename "seg%03d.ts" index.m3u8
python -m http.server 8765 --bind 127.0.0.1

# 2) 跑一次完整链路（清单解析 → 分片 → 合成 → ffprobe 校验）
./hgvd-downloader-v*.exe --xqdtest "http://127.0.0.1:8765/index.m3u8" 冒烟测试课

# 3) 结果在 ~/.hgv_tool/xqdtest.log，末行 === pass=1 ===
```

`--xqdtest` 用临时清单存储与临时下载目录，**不会**污染 `jobs.json` 与用户的下载目录。

## 八、已知限制

- 没有课表自动发现（上游的 ADB 自动化未合并）；需要自己粘链接或导入清单
- **链接带签名有效期**：`sign` / `t` 过期后 403。换链接的办法：把该行移出清单，
  用**同样的课名** + 新链接重新加入 —— 分片目录按成品路径算，所以能接着续传
- 加密清单只走「明文孪生」，不内置 DRM 解密
- 分片并发 12、课间并发 2 是上游实测的稳定值；调高容易触发 CDN 断流
- 直链音频的扩展名靠 ffprobe，探测失败会回落 `.m4a`
