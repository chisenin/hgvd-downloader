# 03 · 开发要点

给要改这个仓库的人：**这里都是踩过的坑**，改代码前扫一眼。

---

## 一、协议层

### 1.1 「HTTP 200 + 空 body」是症状，不是根因

至少有四种成因，**必须分开报**：

| 现象 | 含义 |
|---|---|
| 返回 **JSON**（哪怕 `code≠0`） | 签名是通的，问题在业务参数 |
| `code=101000` | **`video_id_type` 用错**（教学用 1、短剧用 0） |
| 返回 **零字节 body** | 服务端把请求丢弃了（网关故障 / 限流） |

⇒ **绝不要**把空 body 笼统写成「服务端限流」。
⇒ 排查时**先证伪再下结论**：换一个 host、换一个端点、对同一集发两发，
把「客户端实现问题」和「服务端状态问题」分开。

### 1.2 「换 host」是最便宜的一步鉴别

同一个接口换网关就通，说明问题根本不在客户端。
空 body 时**立刻换网关**（秒级），**不要退避等待**（分钟级）。

★ 配套：故障转移分支要**能测**。用 `HGVD_PLAYBACK_HOST` 把必定丢请求的网关
放第一位，就能验证「空 body → 立刻换下一个」真的被执行过 ——
否则这条代码路径可能从没跑过就交付了。

### 1.3 业务错误码不该退避重试

`code=101000` 是参数错，重试一万次也一样。退避只留给真正的网络故障。

### 1.4 批量下载遇到空 body 别空转

播放接口被丢弃时，旧实现会一直退避重试，整批能空转几十分钟。
现在：**连续 2 次空 body 就熔断**，立刻停下并提示改用「提取 App 缓存」。

### 1.5 细节

- 网页版详情页路径是 `/detail?series_id=<id>`（不是 `/series/<id>`），
  正则要**非贪婪**。
- `content_type` 写 `application/x-protobuf`，**实际是 JSON**。
- `x-medusa` 在播放接口上**必须去掉**。
- 备用直链 `backup_url` 解析了但下载器没用过它 —— 主链修好后就没必要了。
- 收藏接口「不带 cookie」和「带假 cookie」返回不同：不带 cookie 返回空列表，
  别误判成「接口挂了」。

## 二、签名链

### 2.1 移植密码学的两个隐形杀手

- **C# 的 `int` 溢出**：`int` 是 32 位有符号，`ts << 1` 在时间戳较大时直接溢出成负数
  ⇒ 签名与预期完全无关。Python 无此问题 ⇒ **「Python 通、C# 不通」时优先查溢出**。
- **PKCS#7 填充值**：填充字节写错不会报错，但服务端解出来不是合法 JSON
  ⇒ 表现与「被限流」一模一样。

### 2.2 黄金向量必须是真实签名

曾经 `golden_headers.json` 里的 `x-argus` 只是 **4 字节时间戳桩**，
真签名从来没被逐字节比对过 ⇒ 移植 bug 长期潜伏，直到真正去比对才暴露。

⇒ 黄金向量要覆盖**播放接口实际校验的那两个头**（`x-argus` / `x-ladon`），
且必须是真实字节级样本。

### 2.3 body 的字节必须完全一致

`x-gorgon` / `x-ss-stub` 都覆盖 body ⇒ 字段顺序、空格、编码都要一样。

## 三、界面层（Avalonia）

### 3.1 容器型子控件别用 Left/Right 对齐

> `Border` 没有子内容 ⇒ `DesiredSize` 恒为 `(0,0)`。
> 填充层设了 `HorizontalAlignment = Left` 且从未被 Measure ⇒
> 排版时宽度被收缩到 `DesiredSize.Width` = **0**
> ⇒ **整块渐变填充被压成 0 宽**，界面上只剩一条空轨道，
> 看起来像"渐变没实现"。

★ **要么显式 Measure，要么用 `Stretch`。**

### 3.2 「界面效果没出来」时先证明它画出来没有

抓窗口像素、沿控件中线输出颜色分段，比看代码可靠得多：

- 渐变存在 ⇒ 能看到连续的颜色过渡（`#9FDFBD → #43B075`）
- 渐变不存在 ⇒ 整条只有一个颜色（轨道色 `#E4EAF3`）

只贴代码容易把方向判错（以为「渐变定义写错了」或「绑定没生效」），
而真实原因可能是**排版把宽度算成了 0**。

### 3.3 「改了值但界面不刷新」

绑定的是**计算属性**（`SizeText` / `SpeedText` / `Percent`）时，
setter 只 `Raise(nameof(自己))` 是不够的 —— **依赖属性必须一起通知**。

⇒ 这类 bug **必须断言通知事件的名字**，只断言最终值测不出来
（值本身是对的，只是界面没刷新）。

### 3.4 其它 Avalonia 坑

- `ToolTip` 是附加属性 → `ToolTip.Tip="..."`，写成属性直接编译失败。
- Avalonia 没有 `DataTrigger` → 换成 VM 上直接暴露 `bool` / `IBrush`。
- `<Window>` 只能有**一个**根子元素 → 否则 `AVLN3000: Content 无法多次赋值`。
- 没有内置 `MessageBox` → 自写 `MsgBox`。
- `Application` 上没有 `MainWindow` / `Shutdown` → 在
  `IClassicDesktopStyleApplicationLifetime` 上。
- `Application.TryFindResource` 不存在 → `Application.Current.Resources.TryGetValue`。
- 后台线程不能调 `Window.Show()` → 用 `Dispatcher.UIThread.Post`。
- 自绘窗口（`SystemDecorations="None"`）要自己做缩放热区。
- 窗口在运行时创建 → App 级资源用 `DynamicResource`，`StaticResource` 可能找不到。

## 四、跨平台 / 编码

### 4.1 Windows 控制台编码

Python 在**输出被重定向到管道**时取 ANSI 代码页，而不是终端编码。
非中文代码页（如 CI runner 的 cp1252）上打印中文会
`UnicodeEncodeError` 直接崩掉。

⇒ 脚本启动时把 stdout/stderr 重配成 UTF-8：

```python
for _stream in (sys.stdout, sys.stderr):
    try:
        _stream.reconfigure(encoding="utf-8", errors="replace")
    except (AttributeError, ValueError):
        pass
```

⇒ CI 里再补一层 `env: PYTHONUTF8=1`（PEP 540 UTF-8 模式）。

★ 注意：中文 Windows 控制台是 GBK（能编码中文），
**本地永远复现不出来** ⇒ 只能在 CI 上暴露。

### 4.2 C# 侧

- `WinExe` 程序默认没有控制台 → 要输出就 `AttachConsole(-1)`（挂父进程），
  并设 `Console.OutputEncoding = Encoding.UTF8`。
- 路径是 UTF-8 → 文件/进程操作一律用宽字符 API
  （`CreateFileW` / `MoveFileW` / `_wfopen_s` / `CreateProcessW`），
  否则按 GBK 解释 → 中文路径全失败。
- 源码里的中文不要用 `\xNN` 转义（十六进制转义贪婪，`\x88A` = 0x88A）→
  直接写 UTF-8，编译加 `/utf-8`。

## 五、下载器

### 5.1 文件名

- 剧名出现两遍（`《标题》` 前缀 + 独立剧名列）→ 清洗时去重。
- Windows 保留名（`CON` / `NUL` / …）→ 自动加前缀。
- 临时文件用 `*.mp4.part`，成功后才改名 —— 半截文件不会被当成成品。

### 5.2 进度

进度百分比用**整数除法**截断（`down * 100 / total`），
显示的是已下载字节的占比，不是估算时长占比。

### 5.3 默认值改了不生效

「改了默认值，用户却还是看到旧值」—— 通常是**只在 UI 层改了默认值，
没改配置文件里的持久化值**（旧配置优先级更高）。
⇒ 改默认值要同时改「新建配置时的初始值」和「读到旧值时的回落逻辑」。

## 六、离线回归

两套回归都不发网络请求：

```bash
python -m tests.run                                          # 85 项
dotnet build hgvd-csharp/src/Hgvd.Tests/Hgvd.Tests.csproj -c Debug --no-restore
./hgvd-csharp/src/Hgvd.Tests/bin/Debug/net8.0-windows/Hgvd.Tests.exe   # 62 项
```

★ 断言**值**测不出「界面不刷新」这类 bug ⇒ 必须断言**通知事件的名字**。
★ 界面回归要跟着发行版走：发行版换了 UI 技术栈，界面回归也要跟着迁移。
