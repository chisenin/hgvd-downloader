# 红果视频下载器

**一个窗口，两个内容源**：红果收藏夹里的剧集、兴趣岛「我的课程」里的课，
都能成批导出成通用 MP4。

> 只处理**你自己账号下有权访问与保存**的内容。工具不提供未购内容的获取能力，
> 也不做 DRM 破解 —— 内容密钥按官方播放器的同一套规则在本地解包。

## 下载即用

到 [Releases](https://github.com/chisenin/hgvd-downloader/releases) 取最新版：

- **推荐** `hgvd-downloader-v*-win-x64.zip`（目录版，54 MB）—— **先「全部解压」**，再双击里面的 exe。
- 备选 `hgvd-downloader-v*.exe`（单文件，58 MB）—— 就一个文件，首次启动慢几秒。

两种形态功能完全一样：.NET 运行时和 ffmpeg / ffprobe 都打包在内，**不需要另装任何东西**。
首次启动会把内置 ffmpeg 解压到 `%LOCALAPPDATA%\hgvd-downloader\runtime\`，之后再开秒起。

> ★ **下之前先看 Release 说明**：只有写明「两个内容源」的包才含兴趣岛。
> `v1.3.0` 及更早的包是**合并前**的构建，只有红果。想立刻用兴趣岛，按「[开发](#开发)」
> 本地构建即可（`cd hgvd-avalonia && ./build.cmd`），产物在 `dist/`。

### 三步

1. 打开程序，左上角选内容源：**红果视频** / **兴趣岛课程**。
2. 点「获取授权」。启动时**不会**自动读模拟器；只有点这个按钮，才去 MuMu 里读**当前源对应 App**
   的登录态（兴趣岛先校验本机缓存、失效才读 MuMu；红果每次重读）。
   定位不到 MuMu 时会弹框让你选一次 `MuMuManager.exe`。
3. 在左栏**勾选**剧目 / 营 —— 分集与课表会依次**追加**到右栏同一张下载清单（可累计，不替换）——
   点「下载」。

清单里每组有自己的标题行（「剧名 · 共 N 集」/「营名 · 共 N 节」/「手动链接」），
**集号各归各的**，多组一起下不会串号。取消勾选只把那一组移出清单。

## 红果收藏夹

面向收藏里是**冷门、教学类**内容的人 —— 这些内容在聚合站基本找不到，只能从自己账号里捞。

| 类型 | 分集来源 | 状态 |
|---|---|---|
| **教学合集**（`book_type=3`） | `album_detail` → `multi_video_model/preload`（key=1001/1000），标准 HEVC + AAC | ✅ 完全可用 |
| **短剧**（`book_type=2`） | `multi_video_detail/preload` → bytevc2，加密且 SPS/PPS 被抹 | ⚠️ 能下载能解密，ffmpeg 解不出画面；批量下载默认跳过 |
| 图书 / 听书 | — | ❌ 服务端没有视频 |

- 下载的是**完整正片**，不是 10 秒试看片段。
- 断点续传（`*.mp4.part` + Range）、已下载跳过（文件在且 ffprobe 时长对得上）、成品时长校验。
- 「**提取App缓存**」：唯一**不经过播放接口**的出片路径。播放接口异常时用它 ——
  从 MuMu 里已播放过的缓存导出标准 MP4。切到兴趣岛时这个按钮会隐藏（只对红果有效）。

## 兴趣岛课程

> 2026-11-21 起，原「兴趣岛视频下载器」(`xqd-downloader` v1.7.1) 的下载内核并入本工具，
> 那个仓库已归档；**后续修复只在这里发布**。

顶栏左上角切到「兴趣岛课程」。这一侧同样**不会在启动时自动取授权** ——
点「获取授权」，从 MuMu 里的**兴趣岛 App** 读一次登录态
（读 WebView 的 Cookie 库，单条 sqlite3 查询，**不需要 adb / root**），之后复用本机缓存。

授权成功后左栏就是「我的课程」：

- 营列表按 **正式营 / 体验营 / 公开课** 分组，可搜索营名、可全选（全选会逐个拉课表，比较慢）
- **勾选一个营** → 自动拉课表 → 整营的课追加到右栏共用清单
- 双击清单里某一行 = 只下这一节；「暂停」只作用于兴趣岛任务，**分片会保留**，可继续
- 手动粘贴链接兜底：左栏底部「链接…」→ 一行一条（`课名 | https://…`、Tab 分隔、纯 URL 都认）；
  也可以「导入…」直接读 `.txt` / `.json`（`links.json` + `names.json` 会按 fileId 合并课名）
- 「重扫」按磁盘成品重判状态；下载中再点一次「下载」即暂停（两源都生效），再点继续

下载链路：

| 环节 | 做法 |
|---|---|
| 课表 | `myCourseListV2`（营）→ `playListOfCourse` / `openCourse/playListOfCourse`（课表） |
| 播放地址 | `getCoursePlayUrl`（每次下载**现场解析**，签名不缓存） |
| 多码率 | 按**画面短边** `min(w,h)` 选流（这批课多为竖屏，按高度会误选最差一路） |
| 加密清单 | 找同目录**明文孪生** `v.f<编号>.m3u8`，**必须时长校验**（同目录常有别的视频） |
| 分片 | 12 片等距抽样估总字节 → 并发下载（12 路）→ **按字节拼接**成 `all.ts` → `ffmpeg -c copy`（concat demuxer 会重置时间戳，成品短 6 秒） |
| 直链音频 | 单请求流式下载，扩展名按 ffprobe 探到的真实容器定 |

## 界面速查

| 控件 | 作用 |
|---|---|
| 品牌区（左上） | 单击开「关于」；拖动移窗；双击最大化 |
| 下载目录 | 改完回车或点别处即生效；目录不可用会**直接报错**，不会偷偷换地方 |
| 获取授权 | 按**当前源**读对应 App 的登录态 |
| 刷新 / 刷新课程 | 重读收藏夹 / 重拉营列表 |
| 全选（兴趣岛） | 三态；逐个拉课表，慢 |
| 链接…（兴趣岛） | 手动粘链接，兜底 |
| 画质 | 红果 1080p/720p/360p；兴趣岛 最高/1080/720/480（按短边） |
| 下载 | 有选中行只下选中的；没选中就下清单里所有待下载 / 失败的 |
| 下载 / 暂停 / 继续 | **一个按钮三态**：空闲=下载；运行中=暂停（红果保留连接与已写进度，兴趣岛保留分片）；暂停中=继续 |
| 双击清单行 | 只下这一条（不看勾选、不受筛选影响） |
| 右键清单行 | 下载这一条 / 重新下载（清缓存）/ 复制链接 / 复制标题 / 打开文件夹 / 移出清单 |
| Delete 键 | 把选中的行移出清单（兴趣岛会同时从 `jobs.json` 删掉） |
| 视图筛选 | 全部 / 待下载 / 下载中 / 已完成 / 失败（5 档） |
| 来源 / 剩余 | 每行标明「红果 / 兴趣岛」，并按剩余字节与速度估算剩余时间 |
| 历史 | 两源共用的下载历史（最近 500 条，同一成品只留一条） |
| 导入… / 清空 | 兴趣岛：读清单文件 / 只清空链接输入框 |
| 重扫 | 兴趣岛：按磁盘成品重判状态 |
| 提取App缓存 | 红果专用：从模拟器导出已播放缓存 |

## 输出

```
红果：  <下载目录>\<剧名>\<序号>.<集名>.mp4
例：全球死考一季\001.第 1 集.mp4

兴趣岛：<下载目录>\兴趣岛\<营名>\<序号>.<课名>.<日期>.mp4
例：兴趣岛\引气归源太极营\001.先导课：解谜自然之道.2026.04.28.mp4

手动链接：<下载目录>\兴趣岛\<课名>.mp4
```

序号从 1 起、与 App 列表顺序一致；Windows 保留名自动加前缀。
下载中的临时文件是 `*.mp4.part` / `*.part.mp4`，成功后才改名，半截文件不会被当成成品。

## 已知限制

- **下载链路目前仅 Windows**（读模拟器登录态那条路径是平台专用），界面层跨平台。
- **短剧**能下能解密，但 bytevc2 抹掉了 SPS/PPS，ffmpeg 解不出画面。
- **建议登录**：红果播放接口匿名也能通，但带登录态更接近真实客户端，也更稳。
- **没有单独的「停止」按钮**：要中止只能暂停后关闭窗口（分片/临时文件会保留，下次续传）。
- 历史窗口是**只读**的：可以看成品路径，但不能从历史里续传或重下。
- 兴趣岛清单的「所属营」靠**分组标题**表示，没有独立列（来源列已有）。
- 两源的「已存在」判定已统一：文件 ≥1MB 且 ffprobe 时长对得上（容差 `max(1s, 0.5%)`）；
  读不出时长时回退到 ≥1MB 的体积门槛。
- 兴趣岛链接任务里的 `sign` / `t` 有有效期，过期会 403 —— 用同样课名重新加入即可，分片接着续。
- 只读**正在运行**的 MuMu 实例；不替你启动模拟器。
- 接口形状会随服务端改版失效：照 [`docs/05-抓包与协议排查.md`](docs/05-抓包与协议排查.md)
  抓一次真机请求，十分钟能定位差异。

1. **范围**：只处理你自己账号下**有权访问与保存**的内容（已购课程、已开通的营、公开课、

2. **技术边界**：不破解 DRM、不绕过付费墙。加密分集用的是服务端**下发给本机播放器**的
   内容密钥，按官方播放器同一套规则解包；不修改、不重分发客户端。
3. **数据**：登录态与清单只落本机 `%USERPROFILE%\.hgv_tool\`，

## 依赖与数据

- **发行版**：Windows 10/11 x64，零安装（ffmpeg / ffprobe 已内置）。
- **Python 版**：Python 3.10+、`requests`、`cryptography`（或 `pycryptodome`）、ffmpeg / ffprobe。
- **本机数据**：`%USERPROFILE%\.hgv_tool\`
  - 红果：`config.json` / `cookie.json` / `device.json` / `devices.json` / `history.json`
  - 兴趣岛：`xqd\cookie.txt` / `xqd\jobs.json` / `xqd\parts\`
  - `python -m hgvd logout` 清除红果登录态；整个目录删掉即彻底重置。
- **内置 ffmpeg**：`%LOCALAPPDATA%\hgvd-downloader\runtime\ffmpeg-<版本>\`，删掉无害，下次启动自动重建。

## 开发

```bash
# 发行版
cd hgvd-avalonia && ./build.cmd        # 或 build.sh；verify = 构建 + 界面自检 + 真下一集

# C# 离线回归（166 项）
dotnet build hgvd-csharp/src/Hgvd.Tests/Hgvd.Tests.csproj -c Debug --configfile hgvd-avalonia/NuGet.config
./hgvd-csharp/src/Hgvd.Tests/bin/Debug/net8.0-windows/Hgvd.Tests.exe

# Python 离线回归（107 项）
python -m tests.run

# 升版本 / 校验（发布前必须一致）
python tools/bump_version.py 1.4.1     # build.cmd + build.sh + csproj 一起改
python tools/check_version.py          # 只查三处是否一致
python tools/check_version.py v1.4.1   # 再核对标签

# 每个 clone 做一次：推标签时自动校验版本号
git config core.hooksPath .githooks
```

命令行开关（发行版 exe）：

```bash
--selftest [series_id]                 # 收藏夹 → 分集 → 播放地址
--uitest                               # 界面交互自检（需真实登录态）
--batchtest [部数]                     # 批量下载冒烟
--demo <series_id> [skip]              # 加载一部剧并真开始下载（便于截图）
--xqdcatalog [营名] [url]              # 兴趣岛课表诊断（只读：列营 / 课表 / 解析地址）
--xqdtest <m3u8 或 mp4 直链> [课名]    # 兴趣岛链路真下一节
```

```
tools/                    探测与打包脚本
```
