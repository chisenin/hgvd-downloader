## 三、授权（只在点「获取授权」时发生）

- 位置：`/data/data/com.qlchat.xingqudao/app_webview/Default/Cookies`
  （兴趣岛是 WebView 壳，`value` 列明文；不是 `encrypted_value`）
- 方式：`MuMuManager.exe sh -v <实例> -c "sqlite3 '<db>' \"<query>\""`
  —— 走模拟器**内部 RPC**，不需要 adbd / root
- 查询域名：`%qianliao%` / `%xqdaolove%` / `%nicegoods%`
- 必需字段 `userId` + `rsessionId`；可选 `caller/platform/ver/deviceType/os`
- **同名 Cookie 顶层域优先**（`.qianliao.net` 覆盖 `m.qianliao.net`）
- 取到后**在线校验**（`myCourseListV2` size=1）；多实例在跑就逐台试，取服务端认的那台
- 落盘：`~/.hgv_tool/xqd/cookie.txt`（与红果的 `cookie.json` 分开）
- ★ 启动**不取授权**、不读 MuMu；只读本机缓存显示状态。点按钮才动。

> 复用红果侧已有的 MuMu 定位/列实例/执行命令逻辑（`Hgvd.Core.Auth.MumuAuth.RunShell`），
> 没有把上游 1000 行 `ToolLocator/MumuAuth` 再抄一遍。

## 四、课表自动发现

1. **营列表**：`POST /financial/api/transfer/gate/course/myCourseListV2`
   `{"page":{"page":1,"size":200}}`（不传 `skyType` 会带回公开课）
2. **分类**：`FINANCIAL` → 正式营，`LAUNCH/INTENTION` → 体验营，其余 → 公开课
3. **课表**：
   - 正式/体验营有 `campId` → `playListOfCourse {campId, onlyCourseCatalogue:true}`
   - 公开课**没有 campId** → `openCourse/playListOfCourse {periodId}`
   - ★ 缓存 key 用 `campId` / `periodId`，**不能用营名**（同名营有多个批次，会互相覆盖）
4. **每节课**：`topicId` / `roomId` / `type` / `startTime` / `duration`
5. **播放地址**：`getCoursePlayUrl {businessId, businessType, topicId, roomId}`
   - 有 campId → `businessType=camp`、`businessId=campId`
   - 公开课 → `businessType=OPEN_COURSE`、`businessId=periodId`
   - 响应里地址可能多层嵌套 → 递归找第一个 `http` 字符串

## 五、手动链接（兜底）

自动发现拿不到时（比如课已下架、只有别人给的地址），左栏底部「链接…」：

```
课名 | https://…/index.m3u8
课名<TAB>https://…/index.m3u8
https://…/index.m3u8
```

- 行尾可标时长 `[48:12]` / `时长=2892`（有时长才做成品校验）
- `#` 注释、`- ` / `1. ` 前缀会被忽略
- 这类任务没有营，成品落 `<下载目录>\兴趣岛\<课名>.mp4`，分组标题叫「手动链接」

## 六、下载链路与判据（实测结论，别改）

1. **先拉清单**：不是 `#EXTM3U` → 直链媒体；含 `EXT-X-STREAM-INF` → 多码率；含 `EXT-X-KEY` → 加密。
2. **多码率按短边 `min(w,h)` 选流**：这批课多为竖屏，按高度会误选最差一路。
3. **加密清单找同目录明文孪生** `v.f<编号>.m3u8`：
   - 编号来自 `video_<num>_` 或 `v.f<num>.m3u8`
   - 请求孪生**必须去掉 `encdomain=cmv1`**，否则 403
   - `sign` 只绑目录和 `t`，不绑文件名
   - **必须时长校验**（容差 `max(1s, 0.5%)`）：同目录常有别的长视频，不校验会下错内容
4. **总字节用 12 片等距抽样外推**；取前 3 片实测高估 37%
5. **分片名 `%05d_<basename>`**：字典序 == 播放序，且跨会话可续传（只有 `?sign=` 变）
6. **必须先字节拼接成 `all.ts` 再喂 ffmpeg**（concat demuxer 会重置时间戳，成品短 6 秒）
7. **进度按内容时长占比**；直链音频才用字节
8. **清理口径**：失败/中止保留分片；成功才清（`KeepParts` 时也留）

## 七、存储与状态

```
%USERPROFILE%\.hgv_tool\xqd\
├── cookie.txt             兴趣岛 Cookie 头（一行）
├── jobs.json              清单 + 状态（进度不落盘）
└── parts\<md5(成品路径)[:16]>\   分片缓存
```

- 成品：`<下载目录>\兴趣岛\<营名>\<序号>.<课名>.<日期>.mp4`（链接任务无营目录）
- 重启后**自动恢复**上次清单（按营分组，已存在的按磁盘重判）
- 非终态一律回到「待下载」；「已存在」= 文件存在且 ≥10KB
- 状态词与红果共用：待下载 / 排队中 / 解析中 / 下载中 / 封装中 / 校验中 / 已完成 / 已存在 / 已暂停 / 失败

## 八、界面语义（两源共用一张表）

- 左栏在「收藏夹 / 我的课程」间切换；右栏、日志、底栏、下载目录**两源共用**
- 勾剧 → 分集追加；勾营 → 课表追加；各自带分组标题行，序号各归各的
- 下载按钮：有选中行只下选中的，否则下所有「待下载 / 失败」的
- 双击某行 = 只下这一条；「暂停」只对兴趣岛队列有效
- 切源**不打断**正在跑的下载，也不清另一源的行
- 授权按钮按**当前源**取对应 App 的登录态；启动只显示本机缓存状态

## 九、怎么验证

离线回归覆盖解析/命名/队列/课表任务（`Hgvd.Tests` 的 `[兴趣岛]` 组，55 项）。
真链路三个开关：

```bash
# 1) 课表诊断（只读）：列营 → 拉一个营的课表 → 解析第一节地址
./hgvd-downloader-v*.exe --xqdcatalog 太极
./hgvd-downloader-v*.exe --xqdcatalog 太极 url     # 额外打印完整播放地址

# 2) 端到端真下一节（产物落系统临时目录）
./hgvd-downloader-v*.exe --xqdtest "<m3u8 或 mp4 直链>" 冒烟测试课

# 3) 本地造 HLS（不依赖外部服务）
ffmpeg -y -f lavfi -i "testsrc=size=640x360:rate=25:duration=12" \
       -f lavfi -i "sine=frequency=440:duration=12" \
       -c:v libx264 -preset veryfast -pix_fmt yuv420p -c:a aac -shortest \
       -f hls -hls_time 4 -hls_list_size 0 -hls_segment_filename "seg%03d.ts" index.m3u8
python -m http.server 8765 --bind 127.0.0.1
./hgvd-downloader-v*.exe --xqdtest "http://127.0.0.1:8765/index.m3u8" 冒烟测试课
```

结果分别写 `~/.hgv_tool/xqdcatalog.log` / `xqdtest.log`，末行 `=== pass=1 ===`。

## 十、已知限制

- 只读**正在运行**的 MuMu 实例；不替你启动模拟器（省内存，也避免副作用）
- 课表缓存只在进程内；换账号/重开程序会重新拉
- 链接任务的 `sign` / `t` 会过期（403）；换链接时用同样课名重新加入即可续传
- 加密清单只走「明文孪生」，不内置 DRM 解密
- 分片并发 12、课间并发 2 是上游实测的稳定值；调高容易触发 CDN 断流
