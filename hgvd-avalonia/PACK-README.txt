红果视频下载器
==============

一个窗口，两个内容源：红果收藏夹里的剧集、兴趣岛「我的课程」里的课，
都能成批导出成通用 MP4。


【两步就能用】

  1. 先把整个压缩包「全部解压」到任意文件夹
  2. 双击 hgvd-downloader-v*.exe

  首次启动会把内置的 ffmpeg 解压到本机缓存（%LOCALAPPDATA%\hgvd-downloader），
  大概几秒钟，之后就快了。


【为什么必须先解压】

  不要直接在压缩包里双击 exe。
  Windows 资源管理器允许那么做，但它只会把 exe 这一个文件解到临时目录，
  旁边的 dll 找不到 —— 程序会闪退，而且不给任何提示。

  正确做法：右键压缩包 → 全部解压。


【这是「目录版」，不是单文件】

  文件夹里那些 .dll 是 .NET 运行时和界面库，删掉任何一个都会启动失败。
  想换地方就整个文件夹一起搬，不要只拷 exe。

  好处是启动比单文件版快，也不会被安全软件误判成「自己解压自己」的加壳程序。


【系统要求】

  Windows 10 / 11，64 位。
  不需要另外装 .NET，运行时已经打包在里面。


【怎么下】

  1. 左上角选内容源：红果视频 / 兴趣岛课程
  2. 点「获取授权」（启动时不会自动读模拟器，只在这一步读）
       红果   → 读红果 App 的登录态
       兴趣岛 → 读兴趣岛 App 的 WebView Cookie
     优先从雷电模拟器读取（adb 位置与设备序列号都自动探测，换机器换盘符不用改配置）；
     没装雷电时自动退回 MuMu；都定位不到会提示手动指定 adb.exe 或 MuMuManager.exe。
  3. 左栏勾选剧目 / 营 —— 条目会自动追加到右栏「下载清单」，可累计多组
  4. 点「下载」；运行中同一个按钮变成「暂停」（两源都生效），再点「继续」接着下
     双击某一行 = 只下这一条；没有单独的停止按钮，暂停后关窗即可（进度/分片保留）

  兴趣岛还可以「链接…」手动粘贴课程地址兜底，或「导入…」读清单文件（txt/json）。
  红果的「提取App缓存」是备用出片路径：播放接口异常时，从模拟器导出已播放缓存。

  清单的常用操作：
    · 上方 5 档筛选：全部 / 待下载 / 下载中 / 已完成 / 失败
    · 每行标明「红果 / 兴趣岛」与剩余时间
    · 右键 = 下载 / 重新下载（清缓存）/ 复制 / 打开文件夹 / 移出清单
    · 选中后按 Delete 也能移出（粘错的链接就靠这个删）
    · 右上角「历史」查看下载记录（最近 500 条）

  红果的清单存在 queue.json，兴趣岛的课表存在 xqd\jobs.json，
  下次启动会自动恢复（重启前没下完的会回到「待下载」）。


【下载目录】

  默认是系统的「下载」文件夹，可以在界面顶部那一栏改。
  如果配的目录不可用（比如移动硬盘拔了），程序会直接报错并说明原因，
  不会偷偷把文件存到别的地方 —— 免得你下完了却找不到。

  成品位置：
    红果   <下载目录>\<剧名>\<序号>.<集名>.mp4
    兴趣岛 <下载目录>\兴趣岛\<营名>\<序号>.<课名>.<日期>.mp4


【数据与卸载】

  登录态、配置、清单都在 %USERPROFILE%\.hgv_tool\，不上传任何账号信息。
  内置的 ffmpeg 在 %LOCALAPPDATA%\hgvd-downloader\runtime\，删掉无害。

  想彻底重置：退出程序，删掉这两个文件夹即可（已下载的成品不会被删）。
